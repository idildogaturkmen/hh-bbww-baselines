# Normalization Mapping Caveat

- Local ggHH normalization is valid according to the author code.
- The local stored `4j` yield does not exactly close to Yang-Li v2 Table SIII.
- The local QCD `4j3b OR 4j2b` population does not correspond one-to-one to a single Table-SIII column.
- No ad-hoc correction factor is used to force paper closure.

Therefore Yang-Li is an external reference, not a one-to-one normalization closure or a substitute for total-background evaluation.
