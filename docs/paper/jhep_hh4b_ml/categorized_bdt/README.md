# c7w train-only nested categorized BDT

This package contains a Delphes-simulation, train-source-group nested-OOF categorized-BDT study. It opens no validation/test payload and no observed data. Exactly-$3b$ to $\geq4b$ transfer is the primary QCD prediction; direct-$\geq4b$ QCD is secondary closure only.

All model-performance values use 1000 paired source-member replicas from the common registry with SHA-256 `37218e5531018ea2a79473bfbee43df657b309cf06d89751509e74b586d9dc29`. Figures contain asymmetric 68% intervals wherever applicable; selection-stability plots are explicitly separate diagnostics.
