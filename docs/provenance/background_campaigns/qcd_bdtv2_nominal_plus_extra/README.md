# QCD BDT-v2 nominal plus extra samples

Purpose: enlarged QCD statistics for the HH→4b BDT tail and categorization study.

Combined samples:
- qcd_bbbb_iht200to400_combined220k_bdtv2
  - nominal v2 120k + extra100k_v3
  - total generated events: 220,000
  - candidate rows: 15,038

- qcd_bbbb_iht400to600_combined120k_bdtv2
  - nominal v2 20k + extra100k_rootkeep_v1
  - total generated events: 120,000
  - candidate rows: 17,761

Important:
These are logical combined samples within the same QCD iHT slices. The iHT-slice cross section is applied once and divided by the total generated events in the combined sample. The component samples are not treated as separate physics backgrounds.
