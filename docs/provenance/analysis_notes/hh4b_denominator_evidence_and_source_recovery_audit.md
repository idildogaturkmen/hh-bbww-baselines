# HH4b denominator-evidence and source-recovery audit

A physical event weight requires a justified campaign denominator. A manifest event count
may be used only after proving a uniform positive nominal generator-weight convention.
Otherwise the denominator must be the signed sum of nominal generator weights.

PN-c3a does not open generator event payloads. It first exhausts the existing
checksum-frozen metadata and approved local text sources:

- structured provenance JSON;
- run cards and generation banners;
- generator and event-summary logs already approved as normalization provenance;
- exact campaign-name references in the repository, production-storage metadata, and the
  user's LPC home text files.

The search excludes ROOT, Parquet, HepMC, LHE, compressed files, archives, shell histories,
credentials, virtual environments, caches, and binary files.

The output separates the 47 standard card-based campaigns from the six nonstandard ggF HH
and importance-sampled hard-QCD campaigns. It freezes a fail-closed access plan for the
next gate but does not authorize generator-payload access, denominators, cross sections,
physical weights, yields, or model thresholds.
