# Software citations to include in paper

## FastJet

The simulation/reconstruction workflow uses FastJet release 3.5.1 for jet clustering and analysis.

FastJet itself requests citation of:

- M. Cacciari, G. P. Salam, and G. Soyez, *FastJet user manual*, Eur. Phys. J. C 72, 1896 (2012), arXiv:1111.6097.
- Optional older FastJet citation: M. Cacciari and G. P. Salam, *Dispelling the N^3 myth for the k_t jet-finder*, Phys. Lett. B 641, 57 (2006), hep-ph/0512210.

Since this analysis uses anti-kT jets, also cite:

- M. Cacciari, G. P. Salam, and G. Soyez, *The anti-kT jet clustering algorithm*, JHEP 04, 063 (2008), arXiv:0802.1189.

Note from FastJet output:

FastJet release 3.5.1 requests citation of EPJC72(2012)1896 [arXiv:1111.6097] for scientific work and optionally PLB641(2006)57 [hep-ph/0512210].
