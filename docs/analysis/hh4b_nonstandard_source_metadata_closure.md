six nonstandard campaigns: two ggF HH campaigns and four importance-sampled hard-QCD
campaigns. It closes all EOS bundle counts, parses QCD pTHat-bin/shard/seed identities,
rechecks the representative provenance archive, and searches approved local text-only
production roots for exact per-shard sums and generator configuration evidence. The QCD
bin ledger treats the highest `pTHat1000toInf` bin as an explicit open-ended interval
\([1000\,\mathrm{GeV},\infty)\), rather than coercing infinity to a finite number.

No ROOT, HepMC, LHE, Parquet, candidate, validation-candidate, or evaluation-candidate
payload is opened. No denominator, QCD stitching rule, cross section, physical weight, or
yield is authorized. The output is an exact targeted recovery plan for any missing metadata.
