signals. The nominal nonoverlapping direct-MC inventory is 4,690,000
backgrounds plus 200,000 signals. The 300,000 overlapping qcd_bbbb events and
the 10,000-event hard-QCD diagnostic testfill remain in the raw inventory but
are excluded from nominal physical addition.

This checkpoint does not assign an integrated luminosity, open event payloads,
construct event-level physical weights, or calculate physical yields. Hard QCD
retains its separate frozen stitching policy and is not converted into the
ordinary-process formula here.
