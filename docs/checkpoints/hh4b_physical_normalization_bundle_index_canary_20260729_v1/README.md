# HH4b representative-bundle index canary

Six representative EOS production bundles were copied sequentially to temporary scratch, byte-size checked, SHA-256 hashed, and indexed through archive headers. The canaries cover ggF HH4b, VBF HH4b, inclusive ttbar, heavy-flavor QCD, importance-sampled hard QCD, and ttZ with a Z-to-bb label.

No archive member was extracted. Event payload contents were not opened. Candidate, validation, and final-evaluation content remained closed. Cross sections and physical yields were not assigned.

The resulting provenance-member candidates are inputs to a later explicit extraction allowlist. The legacy local ttbar production provenance remains a separate blocking recovery task.
