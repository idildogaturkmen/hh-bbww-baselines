# Run-2 luminosity contract freeze

The primary physical-normalization exposure is frozen at 138 fb^-1
(138000 pb^-1) for a 13 TeV CMS 2016-2018 Run-2-equivalent expected-yield
projection using the custom MadGraph-Pythia-Delphes samples.

CMS-HIG-21-018 is the nominal dataset-scope source. CMS-LUM-20-001 is retained
as the current Run-2 luminosity-metrology source, but its complete-Run-2
precision is not silently assigned to this exact 2016-2018 projection. The
luminosity uncertainty and correlations remain a later systematic contract.

The legacy scripts/build_physics_weights.py is not authorized for final
physical normalization. Run-2 plus Run-3 and HL-LHC projections are registered
as planned, energy-aware scenarios but remain unfrozen and unauthorized.

No event payload, physical event weight, or physical yield is produced here.
