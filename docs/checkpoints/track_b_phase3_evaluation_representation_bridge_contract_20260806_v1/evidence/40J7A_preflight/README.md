# Track B Phase 3 evaluation and representation-bridge preflight

## Purpose

This preflight defines how the frozen Track B Sophon reference study supports
the Track A SPA-Net, SPA-Net+ParT, and SPA-Net+JP-JEPA program.

Track A remains the primary training and physics-performance track. Track B is
an external provenance, control-sample, and domain-stress track.

## Direct comparison

Native SPA-Net, SPA-Net+ParT, and SPA-Net+JP-JEPA must be compared on identical
Track A partitions, labels, event weights, output heads, optimization budgets,
and evaluation code.

## Track B contribution

Track B supplies a frozen 18-process external namespace and released-model
response reference. After a validated jet-clustering and constituent-association
bridge exists, it can test embedding distribution shift, process robustness,
tail stability, and complementarity with the Sophon ensemble.

Track B is not yet a direct SPA-Net training dataset because the current frozen
scope does not establish compatible jet objects and truth-assignment labels.
