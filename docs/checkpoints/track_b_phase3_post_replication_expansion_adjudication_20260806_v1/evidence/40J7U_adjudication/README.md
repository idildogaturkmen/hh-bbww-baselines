# Track B post-replication expansion adjudication

This metadata-only bundle evaluates whether to expand beyond the published
four-file canary plus seven-file replication result.

## Current validated evidence

The current Track-B result contains 11 files and 1,152 unweighted events
across QCD, ordinary ttbar, Z+jets, and ZZ. The execution had zero
preprocessing failures, no file or event-UID overlap, and preserved the
released-model probability contract.

## Decision

The recommended action is to pause broad Track-B execution and prioritize
Track-A physical normalization and native model comparison.

The frozen 44-file balanced plan and 46-file high-score-tail plan remain useful
future options, but neither is authorized now. Running them would broaden
descriptive released-model response coverage without resolving physical
weights, independent signal-label provenance, or publication-grade physical
performance claims.

Track B is not abandoned. A smaller targeted follow-up may be designed later
when a specific unresolved scientific question justifies it and the relevant
weight/label dependencies or Track-A milestones have been frozen.
