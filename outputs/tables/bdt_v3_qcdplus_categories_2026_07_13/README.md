# BDT-v3 qcdplus categorized audit

This directory contains HHH-style mutually exclusive categories built from the two BDT-v3 qcdplus scores.

The script reproduces the frozen BDT-v3 qcdplus train/test split and saves the scored test dataframe.

Files:
- scored_test_events_bdt_v3_qcdplus.parquet
- category_yields.csv and .md
- category_background_composition.csv and .md
- category_mass_summary.csv and .md
- category_definitions.csv and .md
- category_audit_auc_summary.csv and .md

CAT0 is diagnostic unless effective background statistics are sufficient.
