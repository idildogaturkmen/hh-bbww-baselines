# HH4b luminosity scaling

Reference working point: previous_v2_loose_mid

Reference luminosity: 450.0 fb^-1

Reference BDT cuts:
- BDT_QCD > 0.775
- BDT_top > 0.5

Reference metrics:
- S/sqrt(B) = 0.1809393197355951
- S/B = 0.0003350783873303
- median B events = 293771.29509135184
- inferred S events = 98.43641180314386

Scaling assumptions:
- S and B scale linearly with luminosity.
- S/B is constant under simple luminosity scaling.
- S/sqrt(B) scales as sqrt(L).
- The 10% background systematic column is only a crude orientation check.
