# AK4/AK8 paper-normalized yield tables

Signal rows use official SM HH cross sections times BR(H->bb)^2. QCD_bbbb and Zbbbb are fiducial generator placeholders, not final CMS-recommended normalizations.

Files:
- `ak4ak8_official_signal_yields.*`: signal-only table using official SM signal normalization.
- `ak4ak8_paper_normalized_candidate_yields.*`: full table, with caveats for placeholder backgrounds.
- `ak4ak8_normalization_caveats.*`: samples that are not final CMS-recommended normalizations.
